# Linux Infrastructure Lab

Laboratório profissional de estudos e práticas em Linux Administration, Infrastructure, DevOps, Automation e Cybersecurity.

## Objetivo

Este projeto documenta minha evolução prática em:

- Linux Administration
- Filesystems (XFS / EXT4)
- Particionamento
- LABEL / UUID
- fstab e montagem automática
- Backup e compressão
- Shell scripting
- Automação
- Infraestrutura Linux
- DevOps fundamentals
- Cybersecurity fundamentals

## Ambiente Utilizado

- Linux Mint 22.3
- VirtualBox
- Rocky Linux
- Debian Linux
- VMs de laboratório Linux Force Security
