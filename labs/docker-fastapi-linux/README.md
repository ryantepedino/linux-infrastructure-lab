# Docker + FastAPI Linux Lab

Laboratório prático de infraestrutura Linux com Docker e FastAPI.

## Objetivo

Demonstrar conhecimentos práticos em Linux, Docker, Docker Compose e publicação de aplicações backend em ambiente containerizado.

## Tecnologias utilizadas

- Linux
- Python 3.12
- FastAPI
- Docker
- Docker Compose

## Como executar

docker compose up --build

## Acessar documentação da API

http://127.0.0.1:8002/docs

## Endpoints

- GET /
- GET /health
- GET /server-info

## Competências demonstradas

- Criação de API backend
- Containerização de aplicação Python
- Uso de Docker Compose
- Execução de serviço em ambiente Linux
- Organização de laboratório técnico
- Documentação para portfólio
