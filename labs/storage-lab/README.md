# Storage Lab — Linux Filesystems and Backup

## Objetivo
Laboratório prático focado em administração Linux, filesystems, montagem automática, backup e compressão de arquivos.

## Ambiente Utilizado
- Linux Mint 22.3
- VirtualBox
- Debian Linux
- VMs Linux Force Security

## Conceitos praticados
- XFS
- EXT4
- LABEL
- UUID
- /etc/fstab
- mount
- df
- du
- tar
- gzip
- xz
- sha1sum

## Objetivo Profissional
Desenvolver experiência prática em Linux Infrastructure, DevOps, Automation e Cybersecurity.
